# NFL WR Combine Analysis

## Project Goal
Investigate whether NFL combine metrics can predict NFL wide receiver success.

## Methods
- Data cleaning and preprocessing
- Exploratory visualization
- Multiple linear regression
- Speed and explosion analysis

## Technologies Used
- R
- ggplot2
- dplyr
- GitHub

## Key Findings
The 40-yard dash showed the strongest relationship with WR success, although overall combine metrics had limited predictive power.

## Repository Structure
- data/: raw datasets
- plots/: saved visualizations
- scripts/: R scripts and analysis
